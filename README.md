# 413 Printing Services — Landing Page

A single-page website for **413 Printing Services**, a print shop located at 413 Dr. Jose Fernandez Street, Mandaluyong, Metro Manila. The page guides visitors through the shop's services, process, hours, and contact details.

🔗 **Live site:** https://413printingservices.vercel.app/

## What's included

- Hero section with shop intro and quick actions (Message on Facebook, Get Directions)
- About section with shop description
- Services overview: Business Cards & Stationery, Document & Photo Printing, ID & Lamination, T-Shirt & Mug Printing
- "How it works" 3-step process guide
- Business hours table
- Contact card (address, phone, email, Facebook, map link)

## Tech

- Plain HTML + CSS (no build step, no dependencies)
- Fonts: Baloo 2, Inter, Space Mono (via Google Fonts)
- Fully responsive (mobile, tablet, desktop)

## File structure

```
index.html   → the entire website (must stay named exactly index.html at the repo root)
README.md    → this file
```

⚠️ **Important:** Do not rename or replace `index.html` with this README. Vercel serves `index.html` as the homepage — `README.md` is documentation only and won't be shown to site visitors.

## Making updates

1. Edit `index.html` directly in this repository (or clone it locally, edit, then push).
2. Commit and push your changes to GitHub.
3. Vercel automatically redeploys within a minute — no manual steps needed.

## Deploying from scratch (reference)

1. Create a GitHub repository and add `index.html` at the root.
2. Go to [vercel.com](https://vercel.com) → **Add New → Project** → import this repository.
3. Leave build settings as default (static site, no build command needed).
4. Click **Deploy**.
5. (Optional) Add a custom domain under **Project Settings → Domains**.
